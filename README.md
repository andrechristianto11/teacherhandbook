# Teacher Handbook

Aplikasi web (PWA) untuk input nilai, absen ekskul Photography, dan catatan siswa.
Data tersimpan di Google Sheets milik guru melalui Apps Script; repo ini hanya berisi tampilan aplikasi
(tanpa data siswa dan tanpa kata sandi).

- `config.js` — URL API Apps Script (boleh dikosongkan; aplikasi akan menanyakannya saat pertama dibuka).
